Reasoning Strategies

Four experimental configurations used in our evaluation

CONFIGURATION A

Direct Answer

Baseline

The model receives the question and generates a response without explicit reasoning instructions.

  • Direct question answering
  • Single model call
  • No critic or verification
Experimental role Baseline comparison
CONFIGURATION B

Reasoning Prompt

Structured Reasoning

The model is instructed to analyze the problem systematically and work through the necessary steps before giving its answer.

  • Structured reasoning instructions
  • Single model call
  • No additional agent
Experimental role Reasoning improvement
CONFIGURATION C

Two-Agent Debate

Solver & Critic

The proposed solution is critically reviewed, and feedback is used to revise the answer.

  • Solver generates an answer
  • Critic identifies potential errors
  • Solver revises the answer
Experimental role Critique and revision
CONFIGURATION D

Solver–Critic–Judge

Multi-Agent Verification

Extends the debate process with an additional judge stage to evaluate the reasoning and revised response.

  • Solver proposes a solution
  • Critic reviews and challenges
  • Judge evaluates the final result
Experimental role Additional evaluation

Experimental Findings

Insights obtained from the final evaluation dataset

BEST PERFORMING CONFIGURATION

Structured Reasoning Outperformed Multi-Agent Debate

Configuration B achieved 92.86% final accuracy (26 out of 28 questions), while Configurations C and D each achieved 89.29% (25 out of 28). In this experiment, adding agent interactions did not improve accuracy beyond the reasoning-prompt baseline.
